## 1. 基本编码规范

- **大小写敏感**：Verilog 严格区分大小写，关键字必须小写
- **范围定义 [MSB:LSB]**：位宽定义使用降序（如 `[15:0]`），符合二进制自然排列
- **不省略 begin/end**：即使只有一条子语句也保留，增强可读性和修改安全性
- **注释符号**：使用 `//` 或 `/* ... */`；宏引用用反引号 `` ` ``（键盘左上角），非单引号
- **使用 HDL 模板**：推荐 Vivado Language Templates，确保正确推断硬件原语
- **少用生僻语句**：仿真器/综合器可能不支持

## 2. 赋值规则

### 核心铁律：严禁混用
- **时序逻辑**用非阻塞赋值 `<=`：结果下个周期生效
- **组合逻辑**用阻塞赋值 `=`：结果立即生效
- **同一个 always 块严禁混用**，否则逻辑混乱或仿真错误

### 阻塞赋值顺序敏感
组合逻辑中阻塞赋值的书写顺序影响功能：
```verilog
// 错误顺序：b 得到旧 a
always @* begin
    b = a + 1;
    a = c;
end
// 正确顺序：b 得到新 a
always @* begin
    a = c;
    b = a + 1;
end
```

### 组合逻辑敏感量表
- 必须包含完整敏感量表，推荐 `always @*`（或 `always_comb` in SV）
- 缺少信号 → 仿真与硬件行为不一致

## 3. 模块结构规范

### 端口声明顺序
```
1. clk, rst_n
2. 前级输入信号（pre_frame_vsync, pre_frame_hsync, pre_frame_de, data）
3. 后级输出信号（post_frame_vsync, post_frame_hsync, post_frame_de, data）
```

### 参数化设计
阈值和常量用 parameter 传递，便于不同场景调参：
```verilog
module Color_Mask #(
    parameter LATENCY = 3,
    parameter D_BG = 8'd16,
    parameter D_BR = 8'd16,
    parameter CB_MIN = 8'd120
) ( ... );
```

### 模块分区注释
```
// reg define
// wire define
// main code
// step1 pipeline mult
// step2 pipeline add
// step3 pipeline div
```

## 4. 状态机设计

### 安全状态机
- 设计必须包含恢复机制，异常情况下回到已知状态
- DFX 场景：用 EOS（序列结束）信号协调复位和去耦

### 编码选择（一般原则）
- **One-hot**：速度快（每位对应一个状态），适合 FPGA（寄存器丰富）
- **Binary**：省寄存器，适合状态数多且速度要求不高的情况

### 三段式状态机
```
段1: 状态转移（时序逻辑，<=）
段2: 状态译码/下一状态计算（组合逻辑，=）
段3: 输出逻辑（组合或时序）
```

## 5. 信号命名惯例

基于项目中实际使用的命名模式：

| 类别 | 前缀/后缀 | 示例 | 说明 |
|------|----------|------|------|
| 前级输入 | `pre_` | `pre_frame_vsync` | 来自上游模块 |
| 后级输出 | `post_` | `post_frame_vsync` | 送往下游模块 |
| 寄存器延迟 | `_r`, `_r2`, `_d0`, `_d1`, `_d2` | `per_frame_vsync_r` | 打1拍/2拍/级0/级1/级2 |
| 乘法系数 | `_m0`, `_m1`, `_m2` | `rgb_r_m0` | 不同系数乘法结果 |
| 差值 | `_diff` | `bg_diff` | B-G差值 |
| 绝对值 | `_abs` | `rg_abs` | \|R-G\| |
| 条件标志 | `_cond`, `_strict`, `_relax` | `blue_cond` | 逻辑判定中间量 |
| 管道穿通 | `_p` | `blue_strict_p` | 跨级传递的标志 |
| 采样值 | `_s` | `m_strict_s` | 采样到下一阶段的值 |
| 边沿检测 | `_pos_flag`, `_neg_flag` | `vsync_pos_flag` | 上升沿/下降沿 |
| 区域特征 | `vf_` | `vf_area`, `vf_sum_s` | 区域级累加统计 |
| 最大值 | `max_` | `max_y1`, `max_num1` | 峰值位置和数值 |
| 计数器 | `_cnt` | `x_cnt`, `y_cnt` | 坐标计数 |
| 使能 | `_en` | `wr_en`, `rd_en` | 写/读使能 |

## 6. 常见错误清单

| 错误 | 影响 | 正确做法 |
|------|------|----------|
| 同一 always 块混用 `=` 和 `<=` | 逻辑混乱/仿真错误 | 时序用 `<=`，组合用 `=`，绝不混用 |
| 组合逻辑缺少完整敏感量表 | 仿真与硬件不一致 | 用 `always @*` |
| 组合逻辑负反馈 `assign b = m + b` | 仿真死循环 | 改为时序逻辑 |
| BRAM 数组加复位 | 无法推断 BRAM，用数千寄存器 | 存储数组不加复位 |
| DSP 乘法器用异步复位 | 寄存器无法吸收到 DSP | 用同步复位 |
| 复位类型混合（DSP/BRAM 内） | 映射失败，额外资源浪费 | 统一复位类型 |
| 仅注释掉复位条件 | 可能信号反向使能 | 创建独立逻辑块分离处理 |
| 异步复位释放不同步 | 亚稳态/recovery violation | 异步复位同步释放 |
| 省略 begin/end | 后续添加语句易出错 | 始终保留 |

## 7. 组合逻辑 vs 时序逻辑

### 区分原则

| 特征 | 组合逻辑 | 时序逻辑 |
|------|----------|----------|
| 赋值 | `=` 阻塞 | `<=` 非阻塞 |
| 敏感量表 | `always @*` 或全列举 | `posedge clk` 或 `posedge clk or negedge rst_n` |
| 输出 | 即时响应输入变化 | 下一个时钟周期生效 |
| 复位需求 | 无 | 通常需要 |
| 反馈 | 严禁负反馈 | 允许（时序延迟保证稳定） |

### 实际项目中的流水线模式

**Color_Preproc / Color_Mask 模式**：
```
stage0: 捕获输入 → 寄存到 _d0
stage1: 简单运算（差值、比较）→ 寄存到 _d1 + 中间结果
stage2: 最终判定 → 寄存到 _d2 + 输出标志
同步信号: 移位寄存器延迟 LATENCY 个周期对齐
```

**Sobel 模式**：
```
step1: 加权求和 (乘法/移位)
step2: 绝对值差
step3: 平方求和 (DSP乘法)
step4: 阈值比较
同步信号: 16-bit 移位寄存器对齐 4 级延迟
```
